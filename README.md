# ⚽ Football Match & Player Performance Analyzer

Ek professional Python-based web application aur mini-project jo football player statistics, match comparison, player ranking, aur **Design and Analysis of Algorithms (DAA)** ke algorithms ko compare karne ke liye banaya gaya hai.

---

## 🚀 Features

- **Season Overview & Dashboard:** Total players, teams, total goals, aur average ratings ke high-contrast metric cards aur interactive charts.
- **Player Performance Analysis:** Team-wise filtering, name search, aur multiple parameters (Performance Score, Goals, Assists, Rating, Pass Accuracy) ke basis par sorting.
- **Match Comparison:** Home aur Away teams ke goals, possession, aur shots on target ka detailed comparison.
- **DAA Algorithm Lab:** 
  - **Sorting:** Merge Sort vs Quick Sort ki performance execution time ke sath comparison (adjustable element slider ke sath).
  - **Searching:** Linear Search vs Binary Search ka execution time aur time complexity analysis.
- **Export Data:** Filtered player data ko CSV format mein download karne ki suvidha.

## 📊 Performance Score Formula

Project ke liye ek custom performance scoring formula use kiya gaya hai:

$$\text{Score} = (\text{Goals} \times 4) + (\text{Assists} \times 3) + (\text{Pass Accuracy} \times 0.08) + (\text{Rating} \times 2)$$

*(Note: Yeh ek illustrative demo scoring formula hai, official FIFA rating nahi.)*
